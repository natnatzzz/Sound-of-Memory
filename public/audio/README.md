# Conversation stimulus

`conversation.wav` is a 29.8-second mono, 22,050 Hz, signed 16-bit PCM WAV, created for this project from overlapping synthesized voices (macOS Samantha and Daniel). The original dialogue discusses a cafe, a train, and a park. No participant audio or microphone recordings are included. The loop has short fades at its boundaries. The app plays `conversation.mp3`, converted from this WAV to 96 kbps mono MP3 at 22,050 Hz (approximately 30 seconds, 359 KB). The WAV is retained as the original source.

This is a synthetic overlapping-conversation stimulus. Replace `conversation.mp3` with an appropriately licensed recording at the same path if a natural conversation is required. Keep the stimulus identical for participants in the same experiment and document any replacement before collecting a new cohort.
